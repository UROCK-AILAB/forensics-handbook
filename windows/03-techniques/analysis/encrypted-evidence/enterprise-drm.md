# DRM 문서 판별 (Enterprise DRM)

> 위치: [암호화 증거 다루기 (Encrypted Evidence)](index.md) > DRM 문서 판별

## 한 줄 요약

DRM 문서 판별은 열리지 않는 문서를 세 갈래로 나누는 일입니다. 단순히 암호를 건 문서, DRM 보안 문서, 형식을 알 수 없는 파일입니다.
한글(HWP) 문서는 `FileHeader` 속성의 비트로 이 차이를 직접 표시합니다.
다른 형식은 알려진 암호 표시와 하나씩 대조해 가며 좁힙니다.
어느 표시와도 맞지 않는 파일은 DRM 이라고 단정하지 않고 "형식 미상" 으로 적습니다.

## 언제 쓰나

- 회사 PC 에서 모은 문서 가운데 열리지 않는 문서가 있을 때
- 열리지 않는 문서를 비밀번호 복구로 넘기기 전에
- 보고서에 문서를 열지 못한 이유를 적어야 할 때

## 절차

1. **실제 형식을 확인합니다.** 확장자가 아니라 파일 앞머리의 서명으로 가립니다. 방법은 [파일 내용 검색](../content-search/index.md) 에 있습니다.
2. **알려진 암호 표시부터 봅니다.** 오피스·ZIP·한글의 암호 표시는 [암호 걸린 문서·압축 파일](password-protected-files.md) 에 있습니다.
3. **오피스 문서라면 `EncryptedPackage` 를 해석할 때 조심합니다.**
   - 암호 걸린 OOXML 은 OLE 파일 안의 `EncryptedPackage` 스트림에 들어갑니다.
   - 오피스에는 권한 관리 (IRM) 기능도 있습니다. IRM 으로 보호한 문서의 저장 구조는 이 페이지에서 다루지 않습니다.
   - 그래서 `EncryptedPackage` 가 보인다는 것만으로 "비밀번호로 잠근 문서" 라고 단정하지 않습니다. "오피스 형식 안에서 암호화한 문서" 까지만 적습니다.
4. **한글 문서라면 속성 비트를 나눠 읽습니다.** 아래 "한글 문서의 DRM 표시" 표를 봅니다.
   - 암호 설정은 bit 1 이고, DRM 보안 문서는 bit 4 입니다. 서로 다른 비트입니다.
   - 켜진 비트를 모두 적습니다.
5. **한글 문서라면 `DocOptions` 스토리지의 스트림을 봅니다.** 어떤 DRM·전자 서명 스트림이 있는지 목록을 적습니다.
6. **어느 표시와도 맞지 않으면 "형식 미상" 으로 분류합니다.**
   - 확장자는 문서인데 알려진 서명과 암호 표시가 하나도 맞지 않는 파일입니다.
   - 이런 파일을 DRM 문서라고 단정하지 않습니다.
   - 같은 PC 에 문서 보안 프로그램을 설치하거나 실행한 흔적이 있는지 찾습니다. [설치 프로그램](../../../02-artifacts/system-account/uninstall.md), [서비스·드라이버](../../../02-artifacts/persistence/services-drivers.md), [어떤 프로그램을 언제 실행했나](../../../04-scenarios/activity/program-execution.md) 를 봅니다.
7. **기록합니다.** 파일마다 실제 형식, 켜진 비트나 표시, 분류(암호·DRM·형식 미상)를 적습니다.

### 한글 문서의 DRM 표시

한컴의 HWP 5.0 명세는 `FileHeader` 스트림 첫 번째 속성에 DRM 관련 비트를 따로 둡니다.
`FileHeader` 의 전체 구성과 암호·배포용 문서 비트는 [암호 걸린 문서·압축 파일](password-protected-files.md) 에 있습니다.

| 비트 | 뜻 |
|---|---|
| bit 4 | DRM 보안 문서 여부 |
| bit 8 | 공인 인증서 암호화 여부 |
| bit 10 | 공인 인증서 DRM 보안 문서 여부 |
| bit 13 | 개인 정보 보안 문서 여부 |

`DocOptions` 스토리지에는 연결 문서, 배포용 문서, 공인인증서 DRM, 전자 서명 정보가 각각 스트림으로 저장됩니다.

| 스트림 | 명세의 설명 |
|---|---|
| `DrmLicense` | DRM Packaging 의 버전 정의 |
| `DrmRootSect` | 암호화 알고리즘 |
| `CertDrmHeader` | DRM Packaging 의 버전 정의 |
| `CertDrmInfo` | 공인인증서 DRM 정보 |
| `DigitalSignature` | 전자 서명 정보 |
| `PublicKeyInfo` | 공개 키 정보 |
| `_LinkDoc` | 연결된 문서 경로 |

- 명세 원문에는 "버전" 을 뜻하는 영어가 `Verision` 으로 적혀 있습니다. 명세의 오타입니다. 원문을 인용할 때는 그대로 둡니다.
- bit 10(공인 인증서 DRM)이 켜진 문서라면 `CertDrmHeader`·`CertDrmInfo` 스트림도 함께 확인합니다.

### 헥스로 한 번 따라가기

아래 값은 **명세로 만든 예시**입니다. 실제 검체에서 나온 값이 아닙니다.
`FileHeader` 오프셋 36 의 속성 DWORD 를 값으로 읽어 비트를 나눕니다.

| 속성 값 (예시) | 켜진 비트 | 분류 |
|---|---|---|
| 0x00000003 | bit 0, bit 1 | 압축한 문서, 암호 설정 → [암호 걸린 문서·압축 파일](password-protected-files.md) |
| 0x00000011 | bit 0, bit 4 | 압축한 문서, DRM 보안 문서 |
| 0x00000401 | bit 0, bit 10 | 압축한 문서, 공인 인증서 DRM 보안 문서 |
| 0x00002001 | bit 0, bit 13 | 압축한 문서, 개인 정보 보안 문서 |

- 0x10 은 bit 4, 0x400 은 bit 10, 0x2000 은 bit 13 입니다.
- 값이 0x00000011 이면 bit 1 은 꺼져 있습니다. 이 문서는 암호 설정 문서가 아니라 DRM 보안 문서로 표시된 것입니다.

## 도구

아래 공개 도구는 예로만 듭니다. 한 도구의 결과에만 기대지 않습니다.
특정 DRM 제품을 가리는 방법은 이 위키에서 다루지 않습니다.

| 도구 | 쓰임 |
|---|---|
| OLE 스트림 보기 도구 (Python `olefile` 등) | HWP 의 `FileHeader` 스트림과 `DocOptions` 스토리지 목록을 봅니다 |
| 파일 형식 식별 도구 (`file` 명령 등) | 앞머리 서명으로 실제 형식을 가립니다 |
| 헥스 편집기 | 속성 DWORD 와 앞머리를 직접 봅니다 |

## 함정과 한계

- **열리지 않으면 비밀번호부터 대입합니다.** HWP 는 암호 설정과 DRM 보안 문서가 다른 비트입니다. 어느 비트가 켜졌는지 먼저 봅니다.
- **`EncryptedPackage` 를 보고 비밀번호 문서라고 적습니다.** IRM 문서의 구조를 확인하지 않은 채 비밀번호 방식이라고 단정하지 않습니다.
- **형식 미상을 DRM 으로 적습니다.** 어느 표시와도 맞지 않는다는 것은 "알 수 없다" 는 뜻일 뿐입니다. 손상된 파일이거나 다른 방식으로 암호화한 파일일 수도 있습니다.
- **bit 13 을 DRM 으로 묶습니다.** 개인 정보 보안 문서는 DRM 보안 문서(bit 4)와 다른 비트입니다. 따로 적습니다.
- **bit 8 과 bit 10 을 같은 뜻으로 봅니다.** bit 8 은 공인 인증서 암호화, bit 10 은 공인 인증서 DRM 보안 문서입니다.
- **제품 이름을 짐작해 적습니다.** 파일만 보고 어느 회사 제품인지 추정하지 않습니다. 설치 흔적으로 확인한 사실만 적습니다.

## 결과를 어떻게 해석하나

- **HWP 의 DRM 비트**: 문서를 저장할 당시 DRM 보안 문서로 표시되어 있었다는 뜻입니다. 누가 DRM 을 적용했는지, 어느 프로그램이 관여했는지는 비트가 말하지 않습니다.
- **`DocOptions` 의 DRM 스트림**: 어떤 DRM 정보가 문서에 들어 있는지를 보여 줍니다. 스트림 안의 값 해석은 명세가 정의한 범위까지만 적습니다.
- **형식 미상 파일**: "열 수 없었다" 와 "왜 열 수 없는지 확인하지 못했다" 를 나눠 씁니다.
- **밖으로 나간 문서**: DRM 문서가 PC 밖으로 나갔는지 판단할 때는 [자료를 밖으로 빼돌렸나](../../../04-scenarios/exfiltration/data-exfiltration/index.md) 를 함께 봅니다.

보고서 문장 예:

- "한글 문서 Z 의 `FileHeader` 속성 값은 0x00000011 이다. bit 4(DRM 보안 문서)가 켜져 있고 bit 1(암호 설정)은 꺼져 있다."
- "파일 W 는 확장자가 `.hwp` 이지만 한글 문서 서명이 없고 알려진 암호 표시도 없다. 형식을 확인하지 못했다."
