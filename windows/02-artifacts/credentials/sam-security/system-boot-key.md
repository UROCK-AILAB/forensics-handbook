# 부트키 구하기 (SYSTEM Boot Key)

> 위치: [레지스트리 속 비밀번호 정보 (SAM·SECURITY)](index.md) > 부트키 구하기

부트키 (Boot Key) 는 SAM 과 SECURITY 하이브의 비밀을 풀 때 맨 처음 필요한 16바이트 열쇠로, SYSTEM 하이브 안에 조각나 숨어 있습니다. 부트키를 먼저 만들어야 [NTLM 비밀번호 해시](nt-hash.md) 와 [LSA 시크릿](lsa-secrets.md) 으로 넘어갑니다.

## 어디서 나오나 · 왜 이렇게 숨겨 두나

Windows 는 SAM·SECURITY 하이브의 비밀을 그대로 두지 않고 한 겹 더 감싸는데, 그 감싼 것을 풀 열쇠가 부트키입니다. 부트키를 하이브 값에 그대로 적어 두면 하이브만 빼내도 다 풀립니다. 그래서 부트키를 값이 아니라 네 키의 클래스 이름 (Class Name) 에 조각내어 흩어 둡니다.

## 어디에 있나

부트키의 재료는 SYSTEM 하이브의 `CurrentControlSet\Control\Lsa` 아래 네 하위 키 `JD`, `Skew1`, `GBG`, `Data` 에 있습니다. 재료는 각 키의 값이 아니라 클래스 이름에 들어 있는데, 클래스 이름은 레지스트리 편집기에 잘 드러나지 않는 항목이라 하이브를 직접 읽는 도구로 꺼냅니다.

오프라인 하이브에서는 `CurrentControlSet` 대신 `ControlSet001` 같은 실제 이름을 씁니다. 이 구조는 [레지스트리 하이브 구조](../../../01-foundations/database-log-formats/registry-hive/index.md) 를 봅니다.

## 만드는 법

1. 네 키 `JD`, `Skew1`, `GBG`, `Data` 의 클래스 이름을 각각 읽습니다. 클래스 이름은 16진수 문자열입니다.
2. 각 문자열을 바이트로 되돌립니다. 한 조각이 4바이트입니다. 네 조각을 `JD`, `Skew1`, `GBG`, `Data` 순서로 이으면 16바이트가 됩니다.
3. 이 16바이트의 순서를 정해진 자리바꿈 배열로 섞습니다.
4. 섞은 16바이트가 부트키입니다.

공개 구현인 Impacket 이 쓰는 자리바꿈 배열은 `[8, 5, 4, 2, 11, 9, 13, 3, 0, 6, 1, 12, 14, 10, 15, 7]` 입니다. 결과의 i 번째 바이트는 이어붙인 16바이트의 (배열의 i 번째 숫자) 번째 바이트입니다.

> 아래는 명세로 만든 예시입니다. 실제 데이터에서 뽑은 값이 아닙니다.
>
> - 이어붙인 16바이트: `00 01 02 03 04 05 06 07 08 09 0a 0b 0c 0d 0e 0f`
> - 배열의 첫 숫자는 8 입니다. 그래서 결과의 첫 바이트는 8번째인 `08` 입니다.
> - 배열의 둘째 숫자는 5 입니다. 그래서 결과의 둘째 바이트는 5번째인 `05` 입니다.
> - 열여섯 자리를 모두 이렇게 옮기면 부트키가 나옵니다.

## 증거로서 의미

- 알 수 있는 것: 부트키가 나오면 같은 컴퓨터에서 함께 모은 SAM·SECURITY 를 풀 수 있습니다.
- 다른 컴퓨터의 SYSTEM 하이브에서 만든 부트키로는 풀리지 않습니다. 옛 방식(0x01)이면 Impacket 이 체크섬 검사에서 실패를 알립니다. 세 하이브가 한 컴퓨터에서 나왔는지 맞춰 보는 데 쓸 수 있습니다.
- 알 수 없는 것: 부트키 자체는 계정도 비밀번호도 아닙니다. 부트키만으로는 어떤 비밀도 읽지 못합니다.

## 함정과 한계

- 세 하이브를 함께 모읍니다. 부트키는 SYSTEM 에서 나오지만, 풀 대상은 SAM 과 SECURITY 에 있습니다.
- 클래스 이름을 값과 헷갈리지 않습니다. 재료는 값이 아니라 클래스 이름입니다.
- 하이브는 사본에서 작업합니다. 압수 이미지에서 꺼낸 원본 하이브를 열면 내용이 바뀔 수 있습니다.
- 부트키를 SysKey 라고도 부릅니다. 다만 이 이름은 이 글의 참고 문헌으로 확정하지 못했습니다.

## 직접 분석해 보기

- 헥스로 한 번: SYSTEM 하이브를 하이브 뷰어로 열어 `Lsa` 아래 네 키의 클래스 이름을 적습니다. 16진 문자열을 바이트로 바꿔 순서대로 잇고, 위 자리바꿈 배열을 적용합니다.
- 공개 도구로 한 번: 아래 도구는 예로만 듭니다.

| 도구 | 부트키와 관련된 기능 |
|---|---|
| Impacket 의 secretsdump.py (공개 코드) | SYSTEM 하이브에서 부트키를 만들어 SAM·SECURITY 복호에 씁니다 |
| 하이브·레지스트리 뷰어 | `Lsa` 아래 네 키의 클래스 이름을 직접 확인합니다 |
