# Windows 디지털 포렌식 위키

Windows 시스템에 남는 흔적을 어떻게 읽고 해석하는지 정리한 한국어 위키입니다. 포렌식을 공부하는 사람과 현업에서 사건을 분석하는 사람을 위해 작성했습니다.

아티팩트가 어디에 있는지뿐만 아니라 그 기록이 왜 생기는지, 무엇을 증명하고 무엇은 증명하지 못하는지까지 설명합니다. 보고서에 어떻게 쓸 수 있는지도 함께 다룹니다.

**읽는 곳: https://urock-ailab.github.io/windows-forensics-wiki-ko/**

## 구성

모두 394쪽이며, 네 갈래로 나뉩니다.

| 갈래 | 쪽 | 다루는 것 |
|---|---:|---|
| **기반 구조** | 62 | NTFS·레지스트리 하이브·ESE·SQLite·EVTX 같은 저장 형식. 여러 아티팩트가 이 형식 위에 기록됩니다 |
| **아티팩트 사전** | 241 | 프리페치·AmCache·SRUM·셸백·USB·브라우저·메신저·이벤트 로그 등 아티팩트 하나에 한 쪽 |
| **분석 기법** | 55 | 증거 수집·라이브 대응·메모리 분석·타임라인·삭제 데이터 복구·암호화된 증거·해시와 YARA·Sigma·보고서 작성 |
| **조사 시나리오** | 36 | "자료를 밖으로 빼돌렸나" 같은 질문 하나에 여러 아티팩트를 엮어 답하는 흐름 |

큰 주제는 허브 쪽이 먼저 전체를 보여 주고, 하위 쪽이 하나씩 깊이 들어갑니다.
