# 삼성 녹스 (Samsung Knox)

삼성 녹스 (Samsung Knox) 는 삼성 기기에 들어간 보안 기능을 묶어 부르는 이름입니다. 이 페이지는 녹스를 조사할 때 삼성 문서로 확인할 질문과, 기기에서 보이는 삼성 보안 관련 이름을 나눠 적습니다.

## 이 페이지를 읽는 법

녹스의 동작은 해당 모델과 One UI 버전의 삼성 문서로 확인해야 해서, 조사할 때 확인할 질문을 표로 정리했습니다. 기기에서 보이는 이름은 adb 일반 셸 권한으로 읽을 수 있고, 이름으로 녹스와 이어져 보여도 실제로 녹스 구성 요소인지는 이름만으로 알 수 없습니다.

부팅 상태와 부트로더 잠금처럼 Android 공통으로 확인한 내용은 [부트로더와 검증 부팅](verified-boot.md) 페이지에, 삼성 보안 폴더는 [보안 폴더와 작업 프로필](secure-folder-work-profile.md) 페이지에 있습니다.

## 삼성 문서로 확인해야 할 질문

아래 질문은 기기 이력과 수집 가능 범위를 판단하는 데 쓰입니다. 답은 해당 모델과 One UI 버전의 삼성 문서로 확인합니다.

| 질문 | 조사에서 쓰일 곳 |
|---|---|
| 녹스 보증 비트 (warranty bit) 는 무엇이고, 언제 바뀌며, 되돌릴 수 있는가 | 기기가 제조사 소프트웨어가 아닌 것으로 부팅된 이력을 판단하는 근거가 되는지 |
| 보증 비트가 바뀐 뒤 쓸 수 없게 되는 기능은 무엇인가(보안 폴더, 결제 기능 등) | 특정 앱이나 보안 폴더에 데이터가 없는 이유를 설명할 수 있는지 |
| 삼성 보안 부팅 (Samsung Secure Boot) 은 AOSP 검증 부팅과 어떻게 다른가 | AOSP 기준의 부팅 상태 색과 경고 문구를 삼성 기기에 그대로 적용할 수 있는지 |
| 실시간 커널 보호 (RKP), DEFEX, 녹스 볼트 (Knox Vault) 는 무엇을 하는가 | 기기에서 도는 소프트웨어를 믿을 수 있는지, 키가 어디에 보관되는지 |
| 녹스 관련 상태가 기기 어디에 남는가(파일 경로, 설정 키, 시스템 속성) | 수집한 데이터에서 녹스 상태를 읽을 수 있는지 |

## 기기에서 보인 삼성 보안 관련 이름

삼성 기기의 설정 값 global 표에는 프로필 추가·삭제·초기화와 이름이 이어지는 키가 있습니다.

```
lock_add_profile
lock_remove_profile
lock_reset_profile
```

이름만 보면 프로필을 더하거나 지우거나 초기화하지 못하게 막는 정책처럼 보이지만, 녹스나 기기 관리 정책과 어떤 관계인지는 값과 삼성 문서로 확인합니다. 설정 값을 읽는 법은 [설정 값](../../02-artifacts/system-account/settings.md) 페이지를, 관리 정책을 거는 앱은 [기기 관리자와 접근성 권한](../../02-artifacts/credentials-security/device-admin-accessibility.md) 페이지를 봅니다.

삼성 기기의 `dumpsys package` Libraries 절에는 삼성 라이브러리가 공유 라이브러리로 등록되어 있습니다. 아래는 필요한 줄만 옮긴 것이고, `<패키지>` 는 패키지 이름을 가린 자리입니다.

```
sec_platform_library ->  (jar) /system/framework/<패키지>
com.samsung.device ->  (jar) /system/framework/com.samsung.device.jar
com.sec.esecomm ->  (jar) /system/framework/esecomm.jar
```

이 라이브러리들이 녹스 구성 요소인지는 이름만으로 알 수 없습니다. 설치 검증을 맡는 패키지 목록에 삼성 패키지가 함께 있다는 점과, 앱 검사·자동 차단과 이름이 이어지는 설정 키는 [앱 샌드박스와 권한](sandbox-permissions.md) 페이지에서 다룹니다.

## 포렌식에서 중요한 점

녹스 상태의 뜻을 삼성 문서로 확인하기 전에는, 보고서에서 녹스 상태를 근거로 기기 이력을 단정하지 않습니다. 기기가 제조사 서명본이 아닌 소프트웨어로 부팅된 적이 있는지 따질 때는 [부트로더와 검증 부팅](verified-boot.md) 페이지의 AOSP 기준 사실을 먼저 쓰고, 삼성 고유의 표시는 해당 모델과 One UI 버전의 삼성 문서로 확인한 뒤에만 덧붙입니다.

## 함정

설정 키나 라이브러리 이름에 삼성·보안과 이어지는 단어가 있다고 해서 녹스 기능으로 단정하지 않습니다. 이름으로 짐작한 뜻은 보고서에 "이름으로 보아" 라고 밝히고, 값과 뜻을 문서로 확인한 것과 나눠 적습니다.

녹스 관련 기능은 모델과 One UI 버전에 따라 다를 수 있다고 보고, 확인한 기기의 모델·Android 버전·One UI 버전을 함께 적습니다.

## 도구

adb 일반 셸 권한으로 `dumpsys package` 와 `settings list global`·`settings list secure` 를 읽으면 위 이름을 볼 수 있습니다. dumpsys 출력을 읽는 법은 [dumpsys 출력](../../02-artifacts/logs/dumpsys.md) 페이지를 봅니다.
