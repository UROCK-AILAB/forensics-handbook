# 카카오맵 (KakaoMap)

## 한 줄 요약

카카오맵 (KakaoMap) 은 국내에서 많이 쓰는 지도 앱이지만, 공개 도구 ALEAPP 에 전용 모듈이 없고 [1] 저장 경로와 표 구조를 다룬 공개 자료도 없어서, 이 페이지는 카카오맵을 조사할 때 따로 챙길 점과 확인해야 할 항목을 정리합니다.

## 무엇을 기록하나 · 왜 생기나

지도 앱에서 찾아볼 기록은 최근 검색, 즐겨찾기(저장한 장소), 길찾기 기록이 중심이지만, 카카오맵이 이런 기록을 기기에 남기는지, 남긴다면 어느 파일에 어떤 모양으로 남기는지는 공개된 분석 자료가 없어 검체로 확인해야 합니다. 카카오 계정이나 카카오톡과 연동해 즐겨찾기 같은 기록을 어디까지 주고받는지도 마찬가지입니다.

그래서 이 페이지에는 경로·파일 이름·표 이름을 적지 않습니다. 앱 폴더를 직접 살펴 구조를 찾는 순서는 [네이버 지도 (NAVER Map)](naver-map.md) 페이지의 "구조 — 직접 찾는 절차" 와 같으니 그 순서를 따르고, 이 페이지에서는 카카오맵에서 달라지는 점만 적습니다.

## 위치와 버전별 차이

| 항목 | 상태 |
|---|---|
| 패키지 이름 | 공개 자료 없음 |
| 앱 데이터 경로·DB 파일 이름 | 공개 자료 없음 |
| 최근 검색·즐겨찾기·길찾기 기록의 표와 칸 | 공개 자료 없음 |
| 시각 단위 | 공개 자료 없음 |
| 카카오 계정·카카오톡과 주고받는 범위 | 공개 자료 없음 |
| ALEAPP 전용 모듈 | 없음(2026-09-25 main 가지의 모듈 목록 기준) [1] |

앱 버전이나 Android 버전, 삼성 One UI 여부에 따른 차이도 검체에서 확인합니다. 앱 데이터 영역의 짜임새는 [앱 데이터 폴더 구조](../../01-foundations/storage/app-data-layout.md), 공용 저장 공간 쪽은 [공용 저장 공간 (Shared Storage·/sdcard)](../../01-foundations/storage/shared-storage.md) 페이지에서 다룹니다.

## 구조

공개된 구조 분석이 없습니다. 네이버 지도 페이지의 절차대로 패키지를 찾을 때는 앱 이름만 보지 말고 APK 서명자까지 확인합니다. 카카오는 카카오톡을 비롯해 여러 앱을 내고 있어서, 폴더 이름에 회사 이름이 들어 있다는 것만으로 카카오맵 폴더라고 정하면 다른 카카오 앱 폴더를 잘못 고를 수 있습니다. APK 이름과 서명 읽기는 [APK 정보 (AndroidManifest·서명)](../embedded-metadata/apk.md), 설치된 앱 목록은 [설치된 앱 (packages.xml)](../app-usage/packages/index.md) 페이지에 있습니다.

찾은 폴더의 파일은 형식을 가린 뒤 검색어·장소 이름·좌표·시각이 들어 있을 만한 표나 파일을 고르고, 시험 기기에서 검색·즐겨찾기·길찾기를 해 본 전후를 비교해 어느 기록이 어느 동작 때 바뀌는지 확인합니다. 이 확인 전에는 표의 뜻을 보고서에 쓰지 않습니다.

## 증거로서 의미

**증명하는 것**

시험 기기로 뜻을 확인한 기록이라면, 그 시각에 앱에서 무엇을 찾아봤는지, 어떤 장소를 저장했는지, 어디로 가는 길을 찾았는지를 알려 줄 수 있습니다. 확인하지 못한 기록은 "이 앱 폴더에 이런 문자열과 좌표가 있다" 는 사실만 증명합니다.

**증명하지 못하는 것**

검색이나 길찾기 기록은 그곳에 실제로 갔다는 증거가 아닙니다. 카카오톡에서 받은 장소 링크를 열어 카카오맵이 떴다면, 그 장소는 사용자가 직접 찾은 곳이 아니라 받은 곳일 수 있지만, 그런 경우 카카오맵 기록에 어떻게 남는지는 알려져 있지 않습니다. 즐겨찾기도 계정 연동으로 넘어왔을 수 있으니, 이 기기에서 저장했다고 단정하지 않습니다.

## 시각 해석

시각 칸의 단위는 알려져 있지 않습니다. 자릿수로 초·밀리초·마이크로초를 어림하고 앱 설치 시각과 수집 시각 사이에 들어오는지 맞춰 보는 방법은 [네이버 지도 (NAVER Map)](naver-map.md) 페이지의 시각 해석과 같습니다. 값을 바꾸는 일반 방법은 [시각 값](../../01-foundations/value-decoding/time-values.md), 현지 시각 기준은 [시간대와 시각 설정 (Time Zone)](../system-account/time-zone.md) 페이지에 있습니다.

## 함정과 한계

첫째, 공개 도구 결과에 카카오맵 항목이 없다고 해서 기록이 없는 것이 아닙니다. ALEAPP 에는 이 앱을 읽는 모듈이 없습니다 [1].

둘째, 인터넷에 떠도는 패키지 이름이나 경로를 확인 없이 옮기지 않습니다.

셋째, 카카오톡 대화 속 장소 공유는 카카오톡 쪽 기록이라서 카카오맵 폴더만 보면 놓칩니다. 카카오톡 쪽은 [카카오톡 (KakaoTalk)](../messengers/kakaotalk/index.md) 페이지에서 다룹니다.

넷째, 서버에 남는 기록은 기기 분석으로 얻을 수 없고, 무엇이 서버에 남는지도 공개 자료가 없습니다. 클라우드 쪽 확보 절차는 [클라우드 데이터 (Google Takeout 등)](../../03-techniques/acquisition/cloud-data.md) 페이지에서 다룹니다.

## 직접 분석해 보기

### 헥스로 한 번

찾은 파일을 헥스 편집기로 열어 앞머리로 형식을 가리고, 좌표로 보이는 정수는 10^6·10^7 로 나눠 국내 위도·경도 범위에 들어오는지 봅니다. 예시 계산과 형식별 페이지 링크는 [네이버 지도 (NAVER Map)](naver-map.md) 페이지의 "헥스로 한 번" 에 있습니다. [구글 지도 (Google Maps)](google-maps.md) 의 DB 칸이 E6 정수를 쓰는 것처럼 확인된 예와 비교하면 단위를 가리기 쉽습니다.

### 공개 도구로 한 번

전용 모듈이 없으니 SQLite 브라우저나 프로토콜 버퍼 디코더 같은 범용 도구로 파일을 하나씩 엽니다. 폴더 전체에서 검색어나 장소 이름을 찾을 때는 [콘텐츠 검색 (Content Search)](../../03-techniques/analysis/content-search.md) 방법을 쓰고, 앱 폴더를 살피는 일반 절차는 [앱 데이터 분석 (App Data Analysis)](../../03-techniques/analysis/app-data-analysis/index.md) 페이지에 있습니다.

## 실습

공개 검체에 카카오맵이 들어 있는 경우는 드물 수 있으니, 필요하면 직접 준비한 시험 기기로 풀어 봅니다.

1. 설치된 카카오 앱이 몇 개이고, 그중 카카오맵을 앱 이름과 서명자로 어떻게 가려냈습니까?
2. 카카오맵 앱 데이터 폴더에 SQLite 파일과 설정 XML 파일은 각각 몇 개입니까?
3. 시험 기기에서 장소 하나를 즐겨찾기에 넣은 전후로 어느 파일이 바뀌었습니까?
4. 카카오톡으로 받은 장소 링크를 열었을 때와 직접 검색했을 때, 카카오맵 기록에 차이가 있습니까?
