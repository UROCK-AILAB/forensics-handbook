# 카카오맵 (KakaoMap)

카카오맵 (KakaoMap, 패키지 net.daum.android.map) 은 국내에서 많이 쓰는 지도 앱이고, 앱 데이터를 모두 평문으로 저장해서 앱 폴더를 확보하면 SQLite 브라우저 같은 범용 도구로 바로 읽을 수 있습니다 [2][3]. 공개 도구 ALEAPP 에는 이 앱을 읽는 모듈이 없어서 [1], 이 페이지는 카카오맵을 조사할 때 따로 챙길 점과 확인할 항목을 정리합니다.

## 무엇을 기록하나 · 왜 생기나

지도 앱을 쓰면 사용자가 이동한 경로와 목적지의 위치 정보가 시간 정보와 함께 남고, 이 기록으로 사용자가 언제 어디로 가려 했는지를 추적할 수 있습니다 [2]. 카카오맵은 이런 데이터를 평문으로 저장해서, 사용자 동작에 따라 생기는 기록을 앱 폴더에서 바로 읽을 수 있습니다 [2].

앱에는 자동차·대중교통·도보·자전거 길찾기, 버스 번호·정류장·장소를 한 번에 찾는 통합 검색, 그룹으로 관리하는 즐겨찾기, 카카오톡 친구의 현재 위치를 보는 친구위치 기능이 있습니다 [3]. 즐겨찾기 그룹은 공유하고 구독할 수 있고, 신체 활동 권한은 사용자가 고른 사람과 실시간 위치를 공유하는 데 씁니다 [3]. 이 기능 목록은 어떤 흔적을 찾아볼지 정하는 데 쓰고, 기기에 그 기록이 파일로 남았다는 근거로 쓰지 않습니다.

| 항목 | 내용 | 근거 |
|---|---|---|
| 패키지 이름 | net.daum.android.map, 개발자 Kakao Corp. | Play 상세 페이지 [3] |
| 저장 방식 | 모든 데이터를 평문으로 저장 | 2022년 분석 [2] |
| DB 파일 이름·표·열 | 앱 판마다 바뀔 수 있어 실제 데이터로 확인 | — |
| 카카오 계정·카카오톡과 주고받는 기록 | 시험 기기에서 동작 전후를 비교해 확인 | — |
| ALEAPP 전용 모듈 | 없음(2026-09-28 main 가지의 모듈 목록 기준) | [1] |

평문 저장은 2022년 논문이 그 무렵의 앱을 분석한 결과라서 [2], 다른 판을 다룰 때는 파일 앞머리가 `SQLite format 3\000` 인지 보고 다시 확인합니다. 앱 버전이나 Android 버전, 삼성 One UI 여부에 따른 차이도 실제 기기에서 확인합니다. 앱 데이터 영역의 짜임새는 [앱 데이터 폴더 구조](../../01-foundations/storage/app-data-layout.md), 공용 저장 공간 쪽은 [공용 저장 공간 (Shared Storage·/sdcard)](../../01-foundations/storage/shared-storage.md) 페이지에서 다룹니다.

## 구조

앱 폴더를 직접 살펴 구조를 찾는 순서는 [네이버 지도 (NAVER Map)](naver-map.md) 페이지의 "구조 — 직접 찾는 절차" 와 같으니 그 순서를 따르고, 여기서는 카카오맵에서 달라지는 점만 적습니다.

패키지를 찾을 때는 net.daum.android.map 이라는 이름만 보지 말고 APK 서명자까지 확인합니다. 카카오는 카카오톡을 비롯해 여러 앱을 내고 있어서, 폴더 이름에 회사 이름이 들어 있다는 것만으로 카카오맵 폴더라고 정하면 다른 카카오 앱 폴더를 잘못 고를 수 있습니다. APK 이름과 서명 읽기는 [APK 정보 (AndroidManifest·서명)](../embedded-metadata/apk.md), 설치된 앱 목록은 [설치된 앱 (packages.xml)](../app-usage/packages/index.md) 페이지에 있습니다.

데이터가 평문이라 [2], 찾은 폴더의 SQLite 파일은 SQLite 브라우저로 바로 열립니다. 표 목록과 `PRAGMA table_info` 결과를 적어 두고, 검색어·장소 이름·좌표·시각이 들어 있을 만한 표를 고릅니다. 그다음 시험 기기에서 검색·즐겨찾기·길찾기를 해 본 전후를 비교해 어느 표가 어느 동작 때 바뀌는지 확인합니다. 이 확인 전에는 표의 뜻을 보고서에 쓰지 않습니다.

## 증거로서 의미

**증명하는 것**

시험 기기로 뜻을 확인한 기록이라면, 그 시각에 앱에서 무엇을 찾아봤는지, 어떤 장소를 즐겨찾기에 넣었는지, 어디로 가는 길을 찾았는지를 알려 줄 수 있습니다. 확인하지 않은 기록은 "이 앱 폴더에 이런 문자열과 좌표가 있다" 는 사실만 증명합니다.

**증명하지 못하는 것**

검색이나 길찾기 기록은 그곳에 실제로 갔다는 증거가 아닙니다. 카카오톡에서 받은 장소 링크를 열어 카카오맵이 떴다면, 그 장소는 사용자가 직접 찾은 곳이 아니라 받은 곳일 수 있습니다. 이런 경우 기록이 어떻게 달라지는지는 시험 기기에서 링크를 열 때와 직접 검색할 때를 비교해 확인합니다. 즐겨찾기는 다른 사람의 그룹을 공유받거나 구독한 것일 수 있고 [3], 계정 동기화로 다른 기기에서 넘어왔을 가능성도 있으니 이 기기에서 저장했다고 단정하지 않습니다.

## 시각 해석

시각 필드의 단위는 표마다 다를 수 있습니다. 자릿수로 초·밀리초·마이크로초를 어림하고 앱 설치 시각과 수집 시각 사이에 들어오는지 맞춰 보는 방법은 [네이버 지도 (NAVER Map)](naver-map.md) 페이지의 시각 해석과 같습니다. 유닉스 시각은 UTC 기준이라 보고서에는 현지 시각으로 옮겨 적습니다. 값을 바꾸는 일반 방법은 [시각 값](../../01-foundations/value-decoding/time-values.md), 현지 시각 기준은 [시간대와 시각 설정 (Time Zone)](../system-account/time-zone.md) 페이지에 있습니다.

## 함정과 한계

첫째, 공개 도구 결과에 카카오맵 항목이 없다고 해서 기록이 없는 것이 아닙니다. ALEAPP 에는 이 앱을 읽는 모듈이 없습니다 [1].

둘째, 인터넷에 떠도는 경로나 표 이름을 확인 없이 옮기지 않습니다. 앱 판마다 저장 방식이 바뀔 수 있습니다.

셋째, 카카오톡 대화 속 장소 공유는 카카오톡 쪽 기록이라서 카카오맵 폴더만 보면 놓칩니다. 카카오톡 쪽은 [카카오톡 (KakaoTalk)](../messengers/kakaotalk/index.md) 페이지에서 다룹니다.

넷째, 같은 국내 지도 앱이라도 저장 방식이 다릅니다. 카카오맵과 [티맵 (TMAP)](tmap.md) 은 평문으로 저장하지만, [네이버 지도 (NAVER Map)](naver-map.md) 는 주요 DB 를 암호화합니다 [2]. 한 앱에서 쓴 방법을 다른 앱에 그대로 적용하지 않습니다.

다섯째, 서버에 남는 기록은 기기 분석으로 얻을 수 없습니다. 클라우드 쪽 확보 절차는 [클라우드 데이터 (Google Takeout 등)](../../03-techniques/acquisition/cloud-data.md) 페이지에서 다룹니다.

## 직접 분석해 보기

### 헥스로 한 번

찾은 파일을 헥스 편집기로 열어 앞머리로 형식을 구분하고, 좌표로 보이는 정수는 10^6·10^7 로 나눠 국내 위도·경도 범위에 들어오는지 봅니다. 예시 계산과 형식별 페이지 링크는 [네이버 지도 (NAVER Map)](naver-map.md) 페이지의 "헥스로 한 번" 에 있습니다. [구글 지도 (Google Maps)](google-maps.md) 의 DB 열이 E6 정수를 쓰는 것처럼 확인된 예와 비교하면 단위를 판별하기 쉽습니다.

### 공개 도구로 한 번

전용 모듈이 없으니 SQLite 브라우저나 프로토콜 버퍼 디코더 같은 범용 도구로 파일을 하나씩 엽니다. 폴더 전체에서 검색어나 장소 이름을 찾을 때는 [콘텐츠 검색 (Content Search)](../../03-techniques/analysis/content-search.md) 방법을 쓰고, 앱 폴더를 살피는 일반 절차는 [앱 데이터 분석 (App Data Analysis)](../../03-techniques/analysis/app-data-analysis/index.md) 페이지에 있습니다.

## 실습

공개 이미지에 카카오맵이 들어 있는 경우는 드물 수 있으니, 필요하면 직접 준비한 시험 기기로 풀어 봅니다.

1. 설치된 카카오 앱이 몇 개이고, 그중 카카오맵을 패키지 이름과 서명자로 어떻게 골라냈습니까?
2. net.daum.android.map 앱 데이터 폴더에 SQLite 파일과 설정 XML 파일은 각각 몇 개이고, SQLite 파일은 모두 `SQLite format 3\000` 으로 시작합니까?
3. 시험 기기에서 장소 하나를 즐겨찾기에 넣은 전후로 어느 파일의 어느 표가 바뀌었습니까?
4. 카카오톡으로 받은 장소 링크를 열었을 때와 직접 검색했을 때, 카카오맵 기록에 차이가 있습니까?
